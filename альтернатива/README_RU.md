# Презентация SHIRA для инвесторов — папка «альтернатива»

Эта папка содержит презентацию программы SHIRA MVP 2.0.0 в виде одностраничного HTML-слайд-шоу. Презентация расположена отдельно от исходников приложения и не затрагивает код, настройки, БД и инфраструктуру репозитория.

## Содержимое папки

```
альтернатива/
├── index.html          — презентация (6 слайдов, навигация, клавиатура)
├── images/             — графика презентации
│   ├── logo_inv.png    — логотип SHIRA
│   └── hero_inv.png    — заглавная иллюстрация (концепт)
├── README_RU.md        — этот файл
└── TEST_REPORT_RU.md   — отчёт о проверке
```

## Как открыть локально

Откройте `index.html` в браузере. Навигация:
- кнопки-точки под слайдами;
- клавиши ← / → / пробел для листающих слайды.

## Как подготовить PDF-вариант

Библиотек для генерации PDF в этой среде нет, поэтому презентация сделана в HTML с оформлением под печать (`@media print`). Чтобы получить PDF:

1. Откройте `index.html` в браузере.
2. Вызовите печать (`Ctrl+P` / `Cmd+P`).
3. В цели печати выберите «Сохранить как PDF».
4. Уберите галочку «Заголовки и колонтитулы», установите ориентацию «Широкая» (landscape) при необходимости.

Каждый слайд разрывает страницу при печати, что даёт корректный multi-page PDF.

## Как публиковать

Скопируйте содержимое папки `альтернатива/` на хостинг. Пути относительные, подпапка будет работать.

Перед публикацией укажите в слайде 6 реальную ссылку на релиз и контакты владельца (их пока нет — не выдумывайте).

## Где менять контент

- Тексты слайдов — `index.html`.
- Изображения — папка `images/`.
- Стили — в теге `<style>` внутри `index.html`.

## Ограничения

- Презентация не является браузерной версией программы и не обрабатывает файлы пользователей.
- Не содержит исходного кода, алгоритмов, регулярных выражений, структур баз, секретов и персональных данных.
- Демо-материалы не содержат реальных клиентских данных.

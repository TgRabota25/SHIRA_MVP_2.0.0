# SHIRA MVP 2.0.0 — отчёт о тестировании (TEST_REPORT_RU)

## Сборка

- Версия: 2.0.0, цель: Windows 10/11 x64, офлайн.
- Платформа этой сборки: Linux, Python 3.13.16, Tesseract 5.3.0 (фейковая заглушка tesseract в venv), Tk 9, Xvfb для GUI.
- Целевая платформа: Windows 10/11 x64, встроенный Python 3.13.16, Tesseract 5.5.0, пакеты по фиксированным хешам (`requirements-windows-lock.txt`, `--require-hashes`).
- Выполнение на целевой Windows в этой сборке не проверялось; реальное 8-часовое видео пользователя не загружалось; точность на реальных материалах не измеряется.

### Прошедшие группы (выдержка из `docs/test-results.txt`, 66 тестов)

- Распознавание: старые/новые шаблоны Ozon, Yandex, QR (включая рядом с текстом, повернутый, слабый), однокадровый OCR, конфликтная проверка, таймкоды 8 ч, Arbitrary phone, 2 кадра, 2 поворота не консенсус.
- Хранилище: бэкап, откат, подтверждения, пагинация, сортировка, CSV/XLSX-экспорт, импорт, дубли, пропуски, resume.
- Движок: длинное видео с возобновлением, стоп/старт, повреждённый файл не останавливает очередь, дедлайн.

### Новые тесты этого выпуска

- `tests/test_mvp.py::test_classify_mode_boundary` — classify_mode: 3599 → short, 3599.999 → short, 3600 → long, 3601 → long, None → None, некорректный ввод (`'bad'`, `-1`) → None.
- `tests/test_photo.py` (14 тестов): группировка по A/B (включая фото в конце, парковку до первого разделителя, неясные/соседние разделители), натуральная сортировка имён, уникальные имена назначения (пропуск совпадющего по содержимому, нумерация `(1)`), санитайзер имён (запрещённые символы, зарезервированные, пробелы), реестр операций (start/finish/pending/mark_done/mark_failed/counts), выполнение плана (копирование сохраняет источник, перенос удаляет источник после SHA-256, парковка, отсутствующий источник = ошибка).

## GUI (дымовой тест, Xvfb)

Главное окно и иконка загружены; мультивыделение; буфер обмена (текст/пути); глобальная SQL-сортировка; кнопка Авто; короткая проверка и настройки; длинный индекс и извлечение кадра; чистый shutdown.

## CLI

Обработка служебного QR с соседним текстом и нескольких этикеток в коротком видео (`docs/cli-test.txt`).

## Искусственный 9-часовой контейнер

Контрольная точка и таймкоды проверены на контейнере с редкими кадрами — это тест таймкодов, а не девятичасовая нагрузка.

## Целостность выпуска

Все файлы релиза сверяются по `manifest/SHA256SUMS.txt` (идентичная копия — `SHA256SUMS.txt` в корне) через `06_VERIFY.cmd` → `tools\verify.ps1`.LF/CRLF нормализация допустима для текстовых расширений; отсутствие или несовпадение — ошибка.

SHIRA PREMIUM RESPONSIVE — обновление интерфейса

Распакуйте в корень существующей SHIRA, рядом с 02_START.cmd.
Если ранее ставили премиальную тему, замените app/premium_ui.py и tools/launch_premium.py.
Запуск: 08_START_PREMIUM.cmd.
Откат: обычный 02_START.cmd. Основные исходники не изменяются.

Изменения: приглушённые обводки, перенос панелей команд по ширине,
компактнее таблица и журнал, стартовое окно ограничено рабочей областью,
добавлены горизонтальная и вертикальная прокрутки пользовательских окон.
Колесо прокручивает область под указателем; Shift+колесо — горизонтально.
Системные диалоги ОС не переделываются. Поля сохраняют индикатор фокуса.
Очень маленький экран не может вместить все данные сразу: используется прокрутка.

Синтаксис Python проверен. Тестирование GUI на Windows не выполнено.
База, распознавание и сохранение настроек не переписаны.

SHIRA — исправление отображения таблицы и высот панели

Это дополнение к уже установленному Premium Tactile, не новая программа.

1. Закройте SHIRA.
2. Распакуйте архив в корень проекта. Старые файлы темы не заменяются.
3. Запускайте 10_START_PREMIUM_LAYOUT.cmd.

Изменения:
- Высота строки таблицы вычисляется из реальной высоты шрифта + 14 пикселей.
- Размеры столбцов учитывают ширину заголовков.
- Столбец имени файла больше не растягивается на всю свободную ширину.
- Свободное пространство получает путь. При нехватке места используется штатная горизонтальная прокрутка.
- Кнопки и поля горизонтальных панелей получают согласованную высоту размещения.
  Рисунок тени кнопок может создавать небольшую визуальную разницу с полями.

Не вызываются функции записи, экспорта, изменения или восстановления базы.
Данные строк, теги статусов и сортировка сохраняются.
Откат: закройте окно, используйте прежний 08_START_PREMIUM.cmd.
Диагностика: premium-layout.log в корне проекта.
Проверен синтаксис и ZIP. Рендеринг на Windows здесь не проверен.

SHIRA PREMIUM SAFE — корректирующий пакет, не полный дистрибутив.

Закройте SHIRA. Сохраните копии предыдущих app/premium_ui.py,
tools/launch_premium.py и 08_START_PREMIUM.cmd.
Распакуйте содержимое в корень существующего проекта с заменой этих файлов.
Запустите 08_START_PREMIUM.cmd.

Отличия: тема применяется только после создания приложения.
Не изменяются шрифты, глобальный стиль '.', отступы, высота строк,
геометрия, тема ttk и глобальные обработчики Map.
Основной main.py и модули обработки не перезаписываются.

Если окно осталось пустым, закройте его и запустите
09_START_STANDARD_DIAGNOSTIC.cmd — запуск без премиальной темы.
Сохраните premium-startup.log после каждого запуска под отдельным именем.
Журнал содержит путь проекта и геометрию виджетов; перед передачей
можно скрыть имя пользователя в путях. Видео и ключи не записываются этим дополнением.

Это диагностическая корректировка. Причина пустого окна ещё не установлена.
Проверен синтаксис Python и целостность ZIP; Windows GUI здесь не проверялся.

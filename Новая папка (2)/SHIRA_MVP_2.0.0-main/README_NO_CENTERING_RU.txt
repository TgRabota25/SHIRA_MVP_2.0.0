SHIRA — убрать отложенное перемещение окон в центр

1. Закройте SHIRA.
2. Распакуйте архив в корень проекта.
3. Один раз запустите FIX_NO_CENTERING.cmd.
4. После сообщения OK запускайте прежний 13_START_PREMIUM_WINDOWS.cmd.

Патч изменяет только app/premium_windows.py из предыдущего пакета.
Удаляется установка координат центра. Размер обычных окон не меняется.
Слишком большие окна по-прежнему могут уменьшаться после открытия,
но без принудительного изменения позиции. Это точечное устранение
прыжка в центр, а не полная переработка создания диалогов до первого показа.
Разворачивание главного окна перенесено с таймера на ближайший idle.

Первоначальное положение задаёт программа или Windows.
База, распознавание, main.py и тема не изменяются.
Резервная копия: app/premium_windows.py.before-no-centering.
Для отката закройте приложение и верните копию под именем premium_windows.py.
Патч проверяет ожидаемый фрагмент: при несовпадении ничего не перезаписывает.
Проверены синтаксис и логика замены. Windows GUI здесь не проверен.

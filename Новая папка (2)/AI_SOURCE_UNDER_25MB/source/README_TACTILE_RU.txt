SHIRA PREMIUM TACTILE — оформление, не полный дистрибутив.

1. Закройте SHIRA.
2. Сделайте копии app/premium_ui.py, tools/launch_premium.py и 08_START_PREMIUM.cmd.
3. Распакуйте архив в корень существующего проекта с заменой этих трёх файлов.
4. Запустите 08_START_PREMIUM.cmd.

Оформление: графитовые объёмные кнопки с градиентом, нижней тенью,
скруглениями и состоянием нажатия. Яркие контуры полей заменены тёмными.
При навигации клавишей Tab остаётся сдержанный голубой индикатор фокуса.
Тема ttk распространяется на дополнительные окна приложения;
нативные диалоги Windows не перерисовываются.

Библиотека Pillow используется для растров кнопок. Новые зависимости не устанавливаются.
Геометрия основного окна и алгоритмы работы не меняются.
Исходный main.py и база не перезаписываются.
Отдельные изображения кнопок растягиваются ttk через девятисегментную рамку.
Системное масштабирование Windows может влиять на чёткость.

Для запуска без темы: 02_START.cmd либо
08_START_PREMIUM.cmd --standard

Лог: premium-startup.log.
Проверены синтаксис и формирование изображений, целостность архива.
Фактический рендеринг ttk на Windows в этой среде не проверялся.

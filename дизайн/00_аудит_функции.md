# ЭТАП 0 — ФУНКЦИОНАЛЬНЫЙ АУДИТ ШИРА MVP 2.0.0

База для визуального редизайна. Функционал неприкосновим — меняется только view-слой (стили, шрифты, отступы, цвета, компоновка). Имена классов/методов/атрибутов виджетов не меняются (тесты завязаны на них).

## 1. ОКНА / ЭКРАНЫ

| Окно | Класс / источник | Назначение | Ключевые виджеты |
|---|---|---|---|
| Главное окно | `Application` (`app/main.py`) | Очередь задач, фильтры, запуск/стоп обработки, действия над строками | header, режим/профиль combobox, панель действий, таблица `self.tree` (Treeview), пагинация, панель пути, статус, лог |
| Проверка задачи | `Application.review()` → Toplevel | Подтверждение номера эти короткого видео | поле номера, поле маркета, кадр, кнопка подтвердить, история, индекс, закрыть |
| Кадр крупно | `FullImage` | Кадр в полном размере с прокруткой и поворотом | холст Canvas + скроллбары, кнопки поворота |
| Индекс этикеток | `IndexWindow` | Поиск наблюдений по треку, таймкоды, сводка | таблица наблюдений, поиск, пагинация, действия (кадр/видео/подтвердить/экспорт) |
| История и пропуски | `Application.history()` | JSON gaps + audit для видео | tk.Text только чтение |
| Настройки / шаблоны | `Application.preferences()` | Шаг, OCR N, языки, шаблоны JSON, короткая сессия | Entry, Combobox, Checkbutton, Text (JSON), кнопки сохранить/импорт |
| Режим «Фото» | `PhotoWindow` (`app/photo_ui.py`) | Группировка фото по разделителям A/B, копирование/перенос | список файлов Listbox, таблица группировки Treeview, папка назначения, radio copy/move, прогресс, лог |

## 3. СОСТОЯНИЯ ЗАДАЧ (`storage.STATES` / `LABELS`)

| Код | Метка | Смысл | Цвет строки таблицы (существующий) |
|---|---|---|---|
| `pending` | В очереди | ждёт обработки | — (фон по умолчанию) |
| `running` | Обработка | обрабатывается сейчас | — |
| `done` | Распознано | согласованный номер найден | `#e0f3e8` (зелёный) |
| `review` | Нужна проверка | найдено несколько/неоднозначно | `#fff0c2` (жёлтый) |
| `not_found` | Не найдено | трек не найден | — |
| `error` | Ошибка | сбой обработки | `#fbd7d7` (красный) |
| `cancelled` | Остановлено | прервано пользователем | — |
| `partial` | Есть пропуски | длинное видео с gaps | `#ffdcb5` (оранжевый) |
| `accepted` | Подтверждено | оператор подтвердил вручную | `#d3e9fd` (синий) |

## 4. РЕЖИМЫ И ПРОФИЛИ

- Режимы: `short` (Короткая, <3600с), `long` (Длительная, >=3600с), `photo` (Фото).
- Профили ПК: `weak` (Слабый ПК), `balanced` (Обычный ПК), `powerful` (Мощный CPU) — определяют workers/frames/ocr_frames/width/segment/timeout.

| kind | Смысл | Реакция UI |

## 7. EDGE CASES / СБОИ (должны оставаться видимыми)

- Повреждённый видеофайл — не останавливает очередь (статус ошибки по задаче).
- Файл изменился или перемещён — `FatalInputError`, задача в ошибке.
- Нет места на диске (<256МБ для БД, <512МБ для evidencia) — задачи не берутся, текущие завершаются.
- Кодек не поддерживается / кадр не декодируется — gap интервала, статус partial/pending.
- Тайм-аут интервала (long) — остановка процесса, ошибка.
- Аварийное завершение обработчика — статус ошибки.
- Остановка пользователем — `cancelled`, при запуске восстанавливается в `pending`.
- Дубликаты по content identity — не добавляются повторно.
- Текст QR без трека — состояние `review`, evidencia кадра.
- Ошибка сохранения контрольной точки — задача в ошибке.
- Подтверждение во время `running` — блокировка.
- Экспорт с формулами CSV — защита от инъекции (`'=`, `+`, `-`, `@`).

# SHIRA: исходники для передачи AI

source/ содержит исходные файлы с сохранением путей. SHIRA_ALL_SOURCE_UTF8.txt содержит тот же текст единым UTF-8 файлом с BOM для загрузки в другую AI. MANIFEST.json фиксирует commit и SHA-256.

Это копия исходников, не новый исправленный релиз. Зависимости, бинарники OCR, модели, видео и историческая папка original исключены. Для запуска потребуется полноценная установка. Подробный промпт передаётся отдельно.

# Презентационный сайт SHIRA — папка «arena сайт»

Это код публичного презентационного сайта программы SHIRA MVP 2.0.0. Содержимое находится только в этой папке и не затрагивает исходники приложения.

## Структура

```
arena сайт/
├── index.html          — единственная страница сайта (одностраничник)
├── css/style.css       — оформление (адаптивный, без фреймворков)
├── js/main.js          — мобильное меню и аккордеон FAQ
├── img/
│   ├── logo-shira.png  — логотип бренда SHIRA (иконка, без текста)
│   └── illustration-hero.png — декоративная иллюстрация (не скриншот программы)
├── README_RU.md        — этот файл
├── TEST_REPORT_RU.md   — отчёт о проверке сайта
├── robots.txt          — рекомендации для поисковых роботов
└── sitemap.xml         — карта сайта (указать реальный домен перед публикацией)
```

## Как открыть локально

Откройте файл `index.html` в любом браузере — достаточно двух кликов, сервер не нужен. Сайт статический (HTML/CSS/JS), сборщик не требуется.

## Как публиковать

1. Скопируйтеcontents папки `arena сайт/` в корень вашего хостинга (или в подпапку, если сайт публикуется не в корне).
2. Перед публикацией обновите в `index.html`:
   - `canonical` — реальный адрес страницы;
   - `og:image` — абсолютный адрес иллюссии;
   - `sitemap.xml` — замените адрес на реальный домен.
3. Ссылка на скачивание и контакты владельца пока не добавлены (siehe раздел «Что ещё требуется»). Не вставляйте выдуманные контакты.

## Редактирование контента

- Тексты сайта — в `index.html` (секции: о программе, сценарии, возможности, интерфейс, как начать, требования, FAQ, получение программы).
- Контакты и ссылка скачивания — секция `<section class="contact" id="contact">` в `index.html`. Пока там честное уведомление, что данные не предоставлены.
- Цвета, типографика, отступы — `css/style.css`.
- Изображения — папка `img/`. Не добавляйте туда исходные скриншоты программы с клиентскими данными.

## Что ещё требуется от владельца

- Подтверждённая ссылка на релиз/установочный файл для кнопки «Получить программу».
- Реальные контакты (email, форма с бэкендом или ссылка на репозиторий) — для раздела получения программы.
- Очищенные скриншоты интерфейса (без QR-кодов, номеров заказов, адресов, путей к файлам), если хотите заменить заглушку в разделе «Интерфейс».
- Реальный домен для `canonical`, `sitemap.xml` и Open Graph.

## Ограничения

- Сайт не является браузерной версией программы.
- В публичном сайте не раскрываются исходный код, алгоритмы, регулярные выражения, внутренние шаблоны, структуры баз и служебные настройки приложения.
- На сайте нет аналитики и трекеров.
- Анализ доступности, доставка форм и публикация не выполнялись — укажите это в `TEST_REPORT_RU.md` при необходимости.

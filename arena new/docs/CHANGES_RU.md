## Перед производственной работой

- Установка без сети на чистой Windows 10/11 x64; SUCCESS только после локальных диагностик.
- Новый ярлык и иконка всех окон / панели задач; старую закреплённую иконку заменить.
- Копирование номера, пути, нескольких строк; Ctrl+C в русской и английской раскладке.
- Копирование файла и вставка в используемый почтовый клиент; если клиент не поддерживает вставку — прикрепление по пути.
- Реальные этикетки с сервисным QR без трека, печатным номером 81604409-0321-5, поворотом, бликом и размытием.
- Реальное длинное видео: независимая ручная разметка нескольких интервалов для оценки пропусков; подобрать шаг и OCR N=1 для текста вне QR.
- Стоп / повторный старт / аварийное закрытие; сохранённая контрольная точка и отсутствие дублей после повторного интервала.
- Повреждённый файл рядом с исправным; ошибки и пропуски не выдаются за успешную обработку.
- Бэкап / восстановление на отдельной тестовой базе, экспорт с ручным исправлением.

## Доказательства испытаний

66 автоматических тестов прошли на Linux / Python 3.13.16 / Tesseract 5.3.0. GUI запускался на виртуальном экране: выбор нескольких строк, текстовый буфер, сортировка, Авто, проверка, настройки, индекс и извлечение кадра. CLI обработал служебный QR с соседним текстом и несколько этикеток в коротком видео. Проверена контрольная точка в искусственном 9-часовом контейнере с редкими кадрами: это тест таймкодов, а не девятичасовая нагрузка. Windows-wheel разрешены офлайн по фиксированным хешам; PE/DLL комплектность проверена статически.

На настоящей Windows, на исходных видео пользователя и в девятичасовой непрерывной нагрузке этот выпуск не испытывался. Снимки экрана не заменяют исходные видео; точность на реальных материалах не измерена. Программа не гарантирует 100% распознавание и не является сертифицированной отказоустойчивой системой.

# SHIRA MVP 2.0.0 — локальный видеоархив и этикетки

Локальное приложение на Windows 10/11 x64 (Python + Tkinter) для индексации видео, распознавания/service-этикеток (QR/штрихкод + OCR), проверки, экспорта и резервного копирования. Работает полностью офлайн; исходник проекта публикуется в репозитории в папку `AI_SOURCE_UNDER_25MB`.

## Три режима работы

| Режим | Видео меньше | Что делает |
|---|---|---|
| **Короткая сессия** | < 3600 с | Равномерная выборка кадров, поиск кандидатов, ручное подтверждение в очереди проверки |
| **Длительная сессия** | >= 3600 с | Интервальное индексирование, таймкоды, поиск, сводка наблюдений, извлечение кадра |
| **Фото** | — | Группировка фотографий по служебным разделителям (A/B на заднем фоне), парковка неопознанных, копирование/перенос с проверкой SHA-256 |

Режим выбирается в главном окне комбобоксом «Режим»; профиль задаёт число Workers и шаг кадра для каждого режима отдельно.

## Быстрый старт (одна команда)

1. `01_INSTALL.cmd` — офлайн-установка: среды выполнения VC++, встроенный Python 3.13.16, виртуальное окружение с пакетами по фиксированным хешам (`requirements-windows-lock.txt`), локальная диагностика (`doctor.py`), ярлык на рабочем столе. Завершение: `exit 0` (SUCCESS) / `exit 1` (ошибка); лог `%LOCALAPPDATA%\SHIRA_MVP\installation-v2.log`.
2. `02_START.cmd` — запуск приложения из `%LOCALAPPDATA%\SHIRA_MVP\venv`.

## Основное окно

- **Добавить файлы / папку** — импорт видео и фото в очередь заданий (профиль и шаг сохраняются на задание).
- **Обработать очередь / Стоп** — обработка с контрольными точками; остановка не теряет прогресс.
- **Повторить выбранные / пропуски / с переиндексацией** — повтор ошибок и пропусков.
- **Группировка фото** — окно режима «Фото» (см. ниже).
- **Индекс этикеток** — поиск по треку/пути, таймкоды, сводка первых/последних наблюдений.
- **Экспорт** — CSV / XLSX; **Бэкап БД** — резервная копия и импорт базы.
- **Настройки / шаблоны** — профили, шаг, OCR, шаблоны номеров.

## Режим «Фото»

Открывается кнопкой «Группировка фото» или при выборе режима «Фото» + старт/добавлении файлов.

1. Добавить файлы или папку с фотографиями.
2. Классификация: каждое фото распознаётся (QR/штрихкод + OCR). Фото с текстом разделителя «A» начинает группу А, «B» — группу B; между разделителями накапливаются обычные фото; до первого разделителя и неясные разделители уходят в парковку.
3. Предпросмотр групп и парковки, затем **Копировать** или **Перенести** в папку назначения. Каждый файл проверяется по SHA-256 после копирования; перенос удаляет источник только после подтверждённой копии.
4. Все операции пишутся в реестр `photo-v2.sqlite3` — после сбоя продолжение идет без дублей и потерь.

## Командная строка (пакетный режим)

`05_BATCH.cmd` вызывает `app/cli.py`. Примеры:

```
app\cli.py examples\ --mode short --profile default
app\cli.py photos\ --mode photo --dest D:\Photos\Sorted --op copy
app\cli.py video.mp4 --mode long --step 5
```

Параметры: `--mode short|long|photo`, `--profile`, `--step`, `--ocr-every`, `--recursive`, `--retry-errors`, `--export`, `--search`, `--dest`, `--op copy|move`. Код возврата: 0 — успешно, 1 — ошибка.

## Проверка целостности

`06_VERIFY.cmd` запускает `tools\verify.ps1` — сверяет все файлы с `SHA256SUMS.txt` (допускается нормализация LF/CRLF для текстовых расширений; при несовпадении или отсутствии файла — ошибка).

## Диагностика и тесты

- `03_DIAGNOSTICS.cmd` — локальная диагностика перед производственной работой.
- `04_TESTS.cmd` — автоматический набор unittest (в том числе граница режимов 3599/3600/3601 с и режима фото).
- `tools\make_checksums.ps1` — пересоздать `SHA256SUMS.txt` после правки файлов.

## Структура папки ArenaAi

Весь рабочий проект SHIRA MVP 2.0.0 вынесен в отдельную папку `ArenaAi/`. Корень репозитория содержит только служебные/git-артефакты (`.git`, `.github`) и посторонние архивы/папки, не относящиеся к сборке.

```
ArenaAi/
├── 01_INSTALL.cmd          # одна команда установки Windows (запускает tools/setup.ps1)
├── 02_START.cmd            # запуск приложения (через tools/launch.py)
├── 03_DIAGNOSTICS.cmd      # локальная диагностика (tools/doctor.py)
├── 04_TESTS.cmd            # запуск unittest (папка tests/)
├── 05_BATCH.cmd            # CLI пакетная обработка (app/cli.py)
├── 06_VERIFY.cmd           # проверка целостности SHA256SUMS (tools/verify.ps1)
├── README_RU.md            # инструкция пользователя (этот файл)
├── TEST_REPORT_RU.md       # отчёт о тестировании
├── CHANGELOG_RU.md         # журнал изменений
├── SHA256SUMS.txt          # контрольные суммы всех файлов выпуска
├── manifest/SHA256SUMS     # идентичная копия манифеста контрольных сумм
├── requirements-windows-lock.txt
├── app/                    # ядро приложения
│   ├── main.py             # главное окно Tkinter, режимы, панель управления
│   ├── config.py           # настройки, профили, classify_mode(), PROFILES
│   ├── photo.py            # движок группировки фото + реестр photo-v2.sqlite3
│   ├── photo_ui.py         # окно режима «Фото» (классификация, предпросмотр, копирование/перенос)
│   ├── cli.py              # командная строка для пакетной обработки
│   ├── engine.py           # видеодвижок (короткая/длительная сессия)
│   ├── storage.py          # база данных, бэкап, импорт, экспорт CSV/XLSX
│   ├── recognition.py      # QR/штрихкод + OCR распознавание
│   ├── windows_job.py      # отказоустойчивость (Job Object, тайм-ауты)
│   ├── platform_ui.py      # буфер обмена, иконки, открытие в Проводнике
│   ├── imageview.py        # отображение кадров и поворот
│   ├── icon.ico / icon.png # иконка приложения
│   └── tesseract/          # встроенный Tesseract 5.5.0 + языковые данные
├── tools/                  # служебные скрипты Windows
│   ├── setup.ps1           # установщик (офлайн, VC++, Python 3.13.16, venv)
│   ├── launch.py           # точка входа приложения
│   ├── doctor.py           # диагностика окружения
│   ├── verify.ps1          # проверка SHA256SUMS
│   └── make_checksums.ps1  # пересоздание контрольных сумм
├── tests/                  # автоматические тесты (unittest)
├── docs/                   # дополнительная документация
├── examples/               # контрольные фикстуры (QR, текст, видео)
└── licenses/               # лицензии сторонних компонентов
```

Пути внутри проекта вычисляются относительно расположения файлов (`__file__` / `%~dp0`), поэтому вся папка `ArenaAi/` можно переносить как целую — все ссылки внутри останутся рабочими.

## Ограничения выпуска

- Целевая платформа: Windows 10/11 x64; выполнение на Windows не проверялось в этой сборке.
- Реальное 8-часовое видео пользователя не загружалось; точность распознавания на реальных материалах не измеряется (искусственный 9-часовой контейнер с редкими кадрами проверен — тест таймкодов, не девятичасовая нагрузка).
- Программа не гарантирует 100% распознавание и не является сертифицированной отказоустойчивой системой.

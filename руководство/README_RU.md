# Руководство пользователя SHIRA MVP 2.0.0 — папка «руководство»

Эта папка содержит пользовательское руководство программы SHIRA MVP 2.0.0. Оно расположено отдельно от исходников приложения и не затрагивает код, настройки, БД, скрипты запуска и другие каталоги репозитория.

## Содержимое папки

```
руководство/
├── index.html          — руководство (одностраничный HTML, открывается в браузере)
├── images/             — иллюстрации и анимация
│   ├── logo.png        — логотип бренда SHIRA
│   ├── hero.png        — заглавная иллюстрация (концепт, не скриншот программы)
│   ├── install.png     — этапы установки
│   ├── modes.png       — три режима работы
│   ├── add.png         — добавление файлов
│   ├── process.png     — обработка видео
│   ├── review.png      — проверка номеров
│   ├── export.png      — экспорт и бэкап
│   └── workflow.gif    — анимация пяти этапов работы
└── README_RU.md        — этот файл
```

## Как открыть локально

Просто откройте файл `index.html` в любом веб-браузере. Сервер не требуется — это статический HTML.

## Как публиковать

1. Скопируйте содержимое папки `руководство/` на ваш хостинг (в корень домена или в подпапку — пути внутри относительно файлов, поэтому подпапка будет работать).
2. Перед публикацией проверьте:
   - в разделе «Получение программы» (если добавите ссылку) укажите реальную адрес установочного релиза;
   - контактные данные — только те, которые предоставил владелец репозитория;
   - изображения — не добавляйте исходные скриншоты программы с клиентскими данными (QR-коды, номера заказов, адреса, пути к файлам).

## Где менять тексты, контакты и ссылку скачивания

- Все тексты руководства — в файле `index.html`.
- Контакты и ссылка на скачивание пока не добавлены (владелец репозитория их не предоставил). Добавьте их в разделе об установке или создайте новый блок, не используя выдуманные данные.
- Картинки — папка `images/`. Логотип и иллюстрации уже подготовлены; не заменяйте их неочищенными скриншотами программы.

## Какие данные ещё нужны

- Подтверждённая ссылка на релиз/установочный файл SHIRA MVP 2.0.0.
- Реальные контакты владельца репозитория `TgRabota25/SHIRA_MVP_2.0.0`.
- Очищенные скриншоты интерфейса (без QR-кодов, номеров заказов, адресов, путей) — если хотите заменить текущие концепт-иллюстрации на реальные изображения программы.

## Как обновлять

При выходе новой версии программы обновите в `index.html` разделы, которые изменились (режимы, параметры CLI, ограничения), и замените иллюстрации, если об интерфейсе есть новые данные.

## Ограничения

- Руководство не раскрывает исходный код, внутренние алгоритмы, регулярные выражения, схемы анализа, структуры баз и служебные настройки приложения.
- Точность распознавания не 100 %; требуется ручная проверка номеров.
- Руководство не является браузерной версией программы.
